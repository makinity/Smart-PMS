# Objective of the Study

The main objective of this study is to develop an **Automation Performance Management Analytics System** for real-time monitoring and optimization of employee tasks.

Specifically, it seeks to:

1. **Develop a System Administrator Module** that will:
   1. Access the system using a System Administrator account.
   2. Synchronize employee records from the HRIS.
   3. Manage user accounts and send activation credentials via Gmail.
   4. Monitor audit trails of system activities.
   5. Perform database backup and restore operations.

2. **Develop a Supervisor Module** with the following functionalities:
   1. Activate account using a verification code sent via Gmail.
   2. Login using Supervisor account credentials.
   3. **Unit Work Plan Creation:**
      1. Create and configure UWP functions, MFOs, and success indicators.
      2. Set QET standards and assign employees to indicators.
      3. Submit UWP to Department Head.
   4. **ORS Monitoring:**
      1. View submitted ORS entries from employees.
      2. Verify supporting evidence.
      3. Rate task quantity, quality, and timeliness.
   5. Review and approve submitted MPORs.
   6. Review and endorse employee Accomplishments.
   7. Review and recommend Employee IDPs.

3. **Develop a Department Head Module** with the following functionalities:
   1. Activate account using a verification code sent via Gmail.
   2. Login using Department Head account credentials.
   3. **Work Planning and OPCR:**
      1. Review and approve UWPs and consolidate to OPCR.
      2. Submit the OPCR to the PMT for approval.
   4. **Performance Reporting:**
      1. Consolidate approved MPORs into a QAR.
      2. Submit the QAR to the PMT for approval.
   5. Endorse Employee Accomplishments to PMT.
   6. Endorse Employee IDPs to PMT.

4. **Develop a Performance Management Team (PMT) Module** with the following functionalities:
   1. Activate account using a verification code sent via Gmail.
   2. Login using PMT account credentials.
   3. Review and approve submitted OPCRs.
   4. Review and approve submitted QARs.
   5. **Calibrate and Release Performance Ratings:**
      1. Review and calibrate Employee Accomplishment Reports.
      2. Finalize employee and office performance ratings.
      3. Publish and release finalized ratings to concerned offices.
   6. Identify top-performing employees for endorsement to the RNR.
   7. **Development Planning:**
      1. Review and add remarks on Employee IDPs.
      2. Transmit approved Employee IDPs to the L&D Section.

5. **Develop an Employee Module** with the following functionalities:
   1. Activate account using a verification code sent via Gmail.
   2. Login using Employee account credentials.
   3. Review and commit IPCR targets.
   4. **Output Recording Sheet (ORS):**
      1. Log and record task accomplishments.
      2. Attach supporting evidence.
      3. Submit ORS entry for supervisor review.
   5. Submit MPOR to Supervisor for approval.
   6. Submit Accomplishment Result for performance evaluation.
   7. View finalized ratings and development interventions.
